## Resumen ejecutivo

Cierra la **Fase 0 — Cimientos técnicos** del proyecto IngenIA365ERP. Entrega
el andamiaje completo de seguridad, autorización, auditoría, persistencia,
soft-delete, adjuntos cifrados, notificaciones y habeas data sobre el que
se construirán los módulos de negocio (Cartera, Contabilidad, Nómina…).

**No incluye lógica de negocio** todavía — esa llega en Fase 1+.

## Cambios técnicos destacables

- **Clean Architecture estricta**: Domain sin dependencias de paquetes
  (validado por `PrincipioII`). Contratos en Application, impl en Infrastructure.
- **CQRS + MediatR** en todos los flujos, con pipeline
  `Validation → Logging → Audit → Performance`.
- **PublicId Guid** externo, `int Id` solo interno (validado por `PrincipioVI`).
- **Audit log append-only** en MongoDB con TTL 5 años, índices por tenant.
- **HSTS + CSP + secure headers** (`SecurityHeadersMiddleware` reescrito T137).
- **Healthchecks** `/health/live` (proceso) + `/health/ready` (deps reales SQL/Mongo/Redis/BlobStore).
